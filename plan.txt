3. Geolocation + Distance (Your Questions Answered)
❓ Do you need an API to calculate distance?

No.

You can compute distance entirely client-side using the
👉 Haversine formula

This uses lat/lng you already have.

Implications:

✅ no API calls
✅ no cost
✅ instant performance
✅ privacy-safe (no server storage)
❓ How to get user location?

Use browser-native:

navigator.geolocation.getCurrentPosition(...)

Important constraints:

requires HTTPS (GitHub Pages ✅)
user must consent
no storage required (you can keep it in memory only)
❓ Privacy concern (“don’t store location”)

You’re safe if you:

do NOT send to Supabase
do NOT persist in localStorage
just use it in-memory for calculation
❓ Opening Google Maps without API

You do NOT need Google Maps API.

Just use a link:

https://www.google.com/maps/dir/?api=1&destination=LAT,LNG

Zero cost. Zero auth.
